## Step 1 — Homepage Formatting Unification

Unify all 7 job cards in `Experience.js` to use the same markup pattern and CSS classes.
Currently SE III uses a different structure from all other entries.

### Inconsistencies Found

**Issue 1 — Competency headers use `<p><strong>` instead of a dedicated class**
`<p><strong>Name</strong> &mdash;</p>` inherits `.job-details p` styling (blue, 0.875rem) —
identical to the date and location lines. Needs its own class. The `&mdash;` should be removed.

**Issue 2 — `<h4>Core Competencies</h4>` has no dedicated style**
Falls through to browser defaults. No `.job h4` rule exists in `styles.css`.

**Issue 3 — Meta info uses 3 separate stacked `<p>` tags per job**
Company, dates, location each on their own line. Should be one consolidated meta row.

**Issue 4 — SE II nested `<ul>` has no visual differentiation**
Sub-bullets use `◦` but no indentation or font-size difference from top-level items.

---

```jsx
<div className="job">
  <div className="job-details">
    <h3>Job Title</h3>

    </p>

    {/* SE III only */}

```
